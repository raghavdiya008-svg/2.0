## 🔄 End-to-End Workflow Stages

### Phase 1: Smart Ingestion & Caching (`media_downloader.py`, `server.py`)
- **What it does:** Accepts a remote URL (YouTube, Google Drive) or a local video from `inputs/`.
- **Audio MD5 Fingerprinting:** Generates an MD5 hash of the raw audio stream. If the hash matches an entry in `global_audio_cache.json`, transcription and diarization are instantly retrieved from cache, bypassing heavy GPU inference.

### Phase 2: Transcription, Boundary Snapping & Curation (`curation_engine.py`, `audio_intelligence.py`)
- **Speech-to-Text:** WhisperX generates phoneme-level word boundaries.
- **Acoustic Snapping:** Any candidate cut generated by an LLM or user import is snapped using `snap_cuts_to_speech_boundaries` to ensure cuts never sever words mid-syllable.
- **Gemini Batch Importer:** The Web UI allows pasting Gemini-generated viral timestamps (JSON or plain lines like `04:15 - 04:55 | Hook`), bypassing local LLM inference.

### Phase 3: Shot Detection & Vision Framing (`engine_vision.py`)
- **PySceneDetect:** Segments the video slice into individual camera shots with a sensitivity threshold of `22.0`.
- **Temporal Hysteresis:** Merges any micro-shots under **1.5 seconds** to prevent rapid camera jumping.
- **Adaptive Shot Routing:**
  - Evaluates 5 evenly distributed frames per shot using InsightFace SCRFD facial landmarks.
  - **Single Subject ($\le 1$ face):** Dynamic 9:16 vertical crop with landmark-anchored Kalman-filtered SmoothGlide tracking.
  - **Multi-Subject ($\ge 2$ faces / banter):** Centered 16:9 video box ($1080 \times 608$) placed at canvas center ($y = 656$) composited over an edge-blurred $1080 \times 1920$ canvas (`boxblur=25:5`).

### Phase 4: Kinetic Subtitles & Safe-Zone Alignment (`caption_engine.py`)
- **Lower-Third Safe Zone:** Default vertical margin is pinned to **`MarginV = 440`**, completely clearing platform UI overlays (TikTok/Reels/Shorts) and remaining visible beneath the 16:9 blur box.
- **Typography:** Arial Black 84pt, primary yellow with white active fill, 4.5px black outline, and 3px deep shadow.
- **Auto-Censoring:** Bleeps/masks vulgar profanities while protecting safe words.

### Phase 5: Hardware-Accelerated Rendering (`engine_ffmpeg.py`, `task_queue.py`)
- **Global 1.0x Native Speed:** Retiming filters (`atempo`, `setpts=PTS/speed`) are completely eliminated to guarantee zero lip-sync audio/video drift.
- **Keyframe-Accurate Slicing:** Executes fast input seek (`-ss [start] -i`) with single-pass NVENC hardware re-encoding (`-cq 18 -preset p4`) and CPU fallback (`libx264 -crf 18 -preset fast`). Sliced audio is resampled at 48 kHz.
- **VRAM Guardian:** Sequential model execution with explicit `torch.cuda.empty_cache()` and `gc.collect()` prevents out-of-memory errors on 15 GB GPUs (Google Colab / Kaggle T4).

## 🖥️ Web Studio Interface Overview (`src/templates/index.html`)

| Section / Modal | Key Controls | Purpose |
| :--- | :--- | :--- |
| **Header Navbar** | • Mode Tabs (`AI Curation Pipeline` vs `Camera Framing Studio`)<br>• Dependency Indicator & Auto-Install | Navigation and runtime verification. |
| **Phase 1: Ingestion** | • URL input (YouTube/Drive)<br>• Local dropdown (`inputs/`)<br>• "Run High-Volume Pipeline" | Ingests media and detects MD5 cache hits. |
| **Terminal Console** | • Real-time log stream<br>• Progress percentage indicator | Displays live status of transcription and curation. |
| **Phase 2: Review Gallery** | • Clip cards with Hook summaries & Virality scores<br>• In/Out time adjustments (`-1s`, `+1s`)<br>• Quick selection filters (`Top 5`, `Top 10`, `Score >= 80`)<br>• "+ Import Gemini Batch" modal | Inspects and selects curated clips for rendering. |
| **Director Preview Modal** | • 📱 9:16 Shorts Safe-Zone Inspector<br>• 📹 16:9 Raw Source Scrub<br>• In/Out point hotkeys (`I`, `O`)<br>• Title Pill toggle & Y slider (80–320px)<br>• Subtitle Y slider & Safe-zone button (440px)<br>• Camera cut shot timeline preview | Human-in-the-loop review and fine-tuning before final rendering. |
| **Batch Control Bar** | • Playback speed selector (default: `1.0x Zero Drift`)<br>• Subtitle Y slider (default: `440px`)<br>• Title Y slider (default: `130px`)<br>• "Render Selected Clips" | Dispatches clips to the FIFO render queue. |
| **Phase 4: Export Panel** | • Real-time batch progress bar<br>• In-browser video players for finished reels<br>• "Download final_reels.zip" | Batch progress tracking and download bundle. |
