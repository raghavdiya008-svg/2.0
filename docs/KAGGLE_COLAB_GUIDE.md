# Running 2.0 Autonomous Video & TV Director on Kaggle / Google Colab GPU

This guide explains how to run the entire system on a **100% local, free GPU** (Kaggle T4 x2/P100 or Colab T4) using local Ollama (`llama3.2:3b`), WhisperX, YOLO, and NVENC rendering. **Zero paid or external cloud LLM APIs are required or used.**

---

## 1. Quick Start on Kaggle

### Step 1: Set Accelerator & Internet
1. Open a new Kaggle Notebook.
2. In the right sidebar:
   - **Accelerator**: Select **GPU T4 x2** (or **GPU P100**).
   - **Internet**: Toggle to **ON** (Required to download Ollama & dependencies).

### Step 2: Clone or Upload Repository
In the first notebook cell:
```bash
!git clone <YOUR_REPO_URL> /kaggle/working/2.0
%cd /kaggle/working/2.0
```

### Step 3: Launch Interactive Web Studio (Recommended)
To run the full Human-in-the-Loop (HITL) Web Studio with Camera Framing & TV Director preview:
```bash
!python kaggle_run_all.py --ui
```
- This automatically:
  1. Installs FFmpeg, libass, nodejs, and GPU packages.
  2. Downloads & starts **local Ollama** with `llama3.2:3b` on the GPU.
  3. Spawns a secure public **Cloudflare tunnel**.
- In the output logs, find your live URL:
  ```text
  🌐 Public: https://xxxx-xxxx-xxxx.trycloudflare.com
  ```
- Click the link to open the full Studio in your browser, where you can:
  - Configure camera framing zones (Host, Guest, Wide, Facecam, Gameplay).
  - Review curated clips with timestamped camera cuts generated by the local Ollama Director.
  - Approve & render with NVENC GPU acceleration directly into `outputs/`.

## 2. Headless Batch Processing on Kaggle

If you just want to place input videos in `inputs/` and render all viral clips in batch:
```bash
# Place your long video clips into inputs/
!python kaggle_run_all.py
```
This runs the complete autonomous pipeline:
1. Audio extraction + WhisperX speech recognition.
2. Silero VAD pause cleaning.
3. Ollama `llama3.2:3b` viral hook curation.
4. Ollama TV Director camera switching (Host / Guest / 9:8 Split Stack).
5. Kinetic karaoke subtitle generation.
6. FFmpeg multi-stream render saved to `outputs/`.

1. **Runtime Type**: `Runtime` -> `Change runtime type` -> select `T4 GPU`.
2. In a Colab code cell:
